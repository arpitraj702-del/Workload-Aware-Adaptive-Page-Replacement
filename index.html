Adaptive Eviction Decisions

About the Algorithms

  • FIFO replaces the page that has been in memory the longest.
  • LRU replaces the page that was used least recently.
  • Optimal replaces the page whose next use is farthest in the future. It needs the future, so it is only a theoretical benchmark.
  • Adaptive runs two hidden "shadow" memories, one FIFO and one LRU, fed with the same references seen so far. When a real replacement is needed, it counts the faults each shadow had in the last 8 references (including the current one) and evicts using the strategy with fewer faults. Ties go to FIFO. It never looks at future references.

Adaptive is a simple heuristic. It is not guaranteed to beat FIFO or LRU, and on some inputs it does worse than one of them.
